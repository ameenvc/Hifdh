Hifdh on your phone

Android preview 1.0.1

Install the test app directly on an Android phone. The Quran and study data are bundled; children’s voice checking requires supported on-device recognition. Online speech and reference audio are available only for adult profiles. Update older previews before child voice use.

Download Android APK

Open the downloaded file and allow installation from your browser if Android asks. This is a preview build, not a Google Play release. Future preview builds signed on another machine may require uninstalling the old preview first.

Real-device microphone behaviour is still being tested. Recitation text matching is not validated Quran mistake detection.

iPhone

Open Hifdh in Safari, tap Share, then Add to Home Screen. This adds the website as a home-screen app. It is not an App Store app and still needs connectivity.
